Clutch Patch – branded game for Garnier

A first‑person experience built for L’Oreal Garnier to introduce their brand into the gaming world inside a fast‑paced, replayable game experience.

Overview

Clutch Patch is a client‑facing project created for L’Oréal Garnier as part of a semester‑long collaboration. The goal was to bring the brand into the game space with an experience that feels like a real game first and a campaign second with twitch integration that boosts engagement. The project was confined inside the school project and did not see light in the wild, but it was a great opportunity to experience the challenges of branded game design and to practice creating engaging gameplay loops under constraints.

My role

I worked as a game and level designer, responsible for the main arena layout, Twitch integration options, and the moment‑to‑moment experience around the Clutch Patch game idea.

  • Defined the core loop and how the branded mechanic plugs into it.
  • Designed and created the level in Unity.
  • Created Twitch integration commands for collaboration between streamer and audience.

Design goals

  • Make the Clutch Patch game feel satisfying, not forced product placement.
  • Keep sessions short and replayable so players can quickly jump back in “for one more try”.
  • Encourage using the Twitch commands for audience to help the streamer.

Process & iteration

The project went through design phases and revisions, starting from written out ideas that were discussed with a representative from L’Oreal Garnier, to prototyping and playtesting in Unity, and finally to a more polished build with improved visuals and feedback.

  • Early tests showed players where escaping the security guards too easily, so the detection process was adjusted.
  • Redesigned the whole goal of the game to better align with the brand vision.
  • Improved the visual design and user feedback to enhance the overall experience.

What I learned

  • Integration between brand elements and gameplay can be seamless when designed thoughtfully.
  • Brands need a clear brand identity to integrate effectively into gameplay.
  • Client constraints can actually help focus design, as long as you keep pushing for fun.
